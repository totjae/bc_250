# AMD BC-250 Custom Cooling Build

AMD BC-250 보드를 일반 PC/서버 형태로 사용할 수 있도록 순정 대형 방열판을 제거하고, 일반 AM4/AM5 CPU 쿨러와 3D 프린팅 마운트를 적용한 실제 조립 기록입니다.

현재 구성은 **Fedora 44 부팅, CPU/RAM/GPU/VRAM/SSD/LAN 점검 및 GPU 5분 부하 테스트까지 정상 통과**한 상태입니다.

> 이 저장소는 우선 현재 실제로 사용 중인 구성과 조립 방법을 기록하기 위한 용도입니다. BC-250은 APU 다이가 노출되어 있으므로 쿨러 체결 시 과도한 압력이나 기울어진 장착에 특히 주의해야 합니다.

## 현재 사용 구성

| 항목 | 사용 부품 / 파일 |
|---|---|
| 보드 | AMD BC-250 |
| APU 쿨러 | **DeepCool AG400 G2** |
| APU 마운트 | `bc250-am5-mount-7mm-bi.step` |
| 후면 클램핑 플레이트 / 팬 캐리어 | `maurice56-jfk13k-clamping-plate-120mm-fan.stl` |
| 후면 팬 스페이서 | `maurice56-jfk13k-fan-spacer.stl` × 4 |
| 후면 냉각 | 표준 120 mm 팬 |
| 후면 백플레이트 | BC-250 순정 금속 백플레이트 유지 |

## APU 쿨러 장착

### 사용 쿨러

**DeepCool AG400 G2** 타워형 공랭 쿨러를 사용했습니다.

BC-250의 순정 방열판을 제거한 뒤, AM4/AM5용 금속 브래킷을 사용할 수 있도록 3D 프린팅 어댑터를 장착했습니다.

### 사용한 APU 마운트

파일:

```text
bc250-am5-mount-7mm-bi.step
```

원본 모델:

- **AM5 CPU cooler mount for the BC250**
- 제작자: **Gadget**
- Printables: https://www.printables.com/model/1826539-am5-cpu-cooler-mount-for-the-bc250
- 라이선스: CC BY-NC 4.0

원본에는 7 mm / 8 mm / 9 mm 높이 버전이 있으며, 쿨러에 포함된 AM5 스페이서 높이에 따라 선택하도록 설계되어 있습니다.

이 빌드에서는 **7 mm 버전**을 사용했습니다.

### AG400 G2 장착 시 중요한 점

AG400 G2에 기본 제공되는 **주황색 AMD 스페이서는 사용하지 않았습니다.**

현재 구성은 다음 순서입니다.

```text
AG400 G2 금속 AM5 브래킷
        ↓
7 mm 3D 프린팅 BC-250 마운트
        ↓
BC-250 PCB
```

즉, 주황색 스페이서를 7 mm 마운트 위에 다시 올리지 않습니다. 스페이서를 함께 사용하면 쿨러 베이스가 APU 다이보다 너무 높아져 제대로 접촉하지 않았습니다.

원본 모델은 M4 히트셋 인서트를 사용하도록 설계되어 있지만, 현재 빌드에서는 **관통 볼트 + 너트 방식**으로 고정했습니다.

볼트 길이는 사용하는 와셔, 너트, 브래킷 조합에 따라 달라질 수 있으므로 조립 상태에서 직접 확인하는 것을 권장합니다.

### APU 접촉 확인

BC-250은 히트스프레더가 없는 **bare die** 구조이므로 장착 후 써멀페이스트 전사 상태를 확인했습니다.

현재 7 mm 마운트에서는 APU 다이 전체에 써멀페이스트가 고르게 전사되는 것을 확인했고, 이후 부하 테스트에서도 정상적인 온도를 확인했습니다.

쿨러를 조일 때는 양쪽 스프링 나사를 번갈아 조금씩 조여 한쪽에 압력이 몰리지 않도록 하는 것이 좋습니다.

## 후면 GDDR6 / 백플레이트 냉각

BC-250 후면에는 GDDR6 메모리가 위치하므로 순정 금속 백플레이트를 그대로 유지하고, 후면에 120 mm 팬을 추가했습니다.

사용한 파일:

```text
maurice56-jfk13k-clamping-plate-120mm-fan.stl
maurice56-jfk13k-fan-spacer.stl
```

원본 프로젝트:

- **BC-250 Mount for Jiushark JF13K (VRM Airflow Directed)**
- 제작자: **Maurice56**

전체 JF13K 마운트를 사용한 것은 아니며, 이 빌드에서는 그중 **후면 클램핑 플레이트 / 120 mm 팬 캐리어와 팬 스페이서**를 사용했습니다.

### 후면 플레이트 주요 구조

- BC-250 순정 금속 백플레이트를 지지하는 클램핑 플레이트
- 표준 **120 mm 팬** 장착 가능
- 표준 팬 홀 간격 약 **105 mm**
- 팬과 플레이트 사이 **10 mm 스페이서** 사용
- 원본 설계의 체결 규격은 M3 기반
- 원본 설계 기준 팬 체결에는 **M3×40** 나사 사용

팬 스페이서는 외형상 10 mm보다 길어 보일 수 있지만, 일부는 팬 체결 홀 안으로 들어가는 위치 결정용 돌기이며 실제 팬과 플레이트 사이 간격은 약 10 mm입니다.

## 3D 프린팅 재료

보드 주변, 특히 VRM 부근은 온도가 높아질 수 있으므로 열에 약한 PLA보다는 다음 계열을 권장합니다.

- PETG
- ABS
- ASA
- PC

현재 사용 부품 역시 장시간 열을 받을 수 있다는 점을 고려해야 합니다.

## 주의 사항

### 1. APU 다이 파손 주의

BC-250 APU는 다이가 직접 노출되어 있습니다. 쿨러를 한쪽만 먼저 강하게 조이거나 지나치게 높은 체결압을 주면 다이를 손상시킬 수 있습니다.

### 2. 7 mm 마운트가 모든 쿨러에 맞는 것은 아님

7 mm는 현재 AG400 G2 구성에서 실제 접촉을 확인한 값입니다. 다른 쿨러는 브래킷과 스페이서 높이가 다르므로 그대로 적용하면 안 됩니다.

### 3. VRM 냉각은 별도로 고려

AG400 G2는 APU 냉각 성능에는 충분한 여유가 있었지만 타워형 쿨러라 보드 전원부에 직접 바람을 내려 보내는 구조는 아닙니다.

순정 전면 방열판을 제거한 상태에서는 **VRM에 별도 방열판 또는 직접적인 에어플로우를 추가하는 것을 권장**합니다.

후면 120 mm 팬은 순정 금속 백플레이트와 후면 GDDR6 냉각을 보조하기 위한 구성입니다.
